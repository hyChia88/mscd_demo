Slide 3 · gap_map
Three Gaps — What the Current Landscape Cannot Do
← AEC Tech Tools
← Digital Platforms
← AI Technologies
SEMANTIC GAP

Visual evidence ≠ schema-structured data

  • Tools translate modalities but miss IFC graph topology [36,11,32]
  • VLMs learn pixel shortcuts, not spatial predicates
  • No tool grounds a site photo to an IFC GUID reliably [24,38]
WORKFLOW GAP

No full loop: field → IFC element → compliance

  • Linking observation to IFC element is manual and costly
  • RFID + BIM [16] is specialised, not generalised
  • Evidence is lost before it reaches the compliance schema
AI TECHNOLOGY GAP

General-purpose models in a domain-specific context

  • Training data: generic CV formats, not IFC hierarchy [27,35]
  • GPT-4 reasoning ≠ construction topology [6,23,30]
  • Most work generates geometry, skips regulatory schemas [11,19]
We lack an interpreter layer that is simultaneously: multimodal  ·  schema-aware (IFC topology)  ·  hallucination-free
