## Phase 0 — Storey Normalisation（独立，必须先做）

**文件**: `src/ifc_engine.py`
**根因**: `find_elements_in_space("level 6")` 对 `"6 - sixth floor"` 做
`"level 6" in "6 - sixth floor"` → `False`。所有 storey 过滤全部失效。
**预期效果**: storey match 0% → 50%+，GUID accuracy 预计 +8~15pp

**设计原则（v2 — LLM Structured Parsing）**:

> **核心分工原则**: 把 IFC 空间层级（Storey + Space）全部 LLM 结构化，构件层级交给符号系统。
> 这是 Neuro-Symbolic 架构在数据预处理层最干净的边界。

```
IFC 空间层级 (container)        → LLM 结构化解析层      (Phase 0)
─────────────────────────────────────────────────────────────
IfcBuildingStorey               → {floor_num, category}
  e.g. "6 - Sixth Floor"        → {floor_num: 6, category: "normal"}
  e.g. "G/F Lobby"              → {floor_num: 0, category: "ground"}

IfcSpace                        → {space_type, unit_id}
  e.g. "Kitchen-3B"             → {space_type: "kitchen",  unit_id: "3B"}
  e.g. "主卧"                   → {space_type: "master_bedroom", unit_id: null}

IFC 构件层级 (element)          → 符号/结构化查询层      (Phase 1b / 5)
─────────────────────────────────────────────────────────────
IfcElement 属性                 → Pset 直接读取           (Phase 1b)
  e.g. Pset_WallCommon.IsExternal, FireRating — 已是结构化数据，LLM 无增益

IfcElement 关系                 → Neo4j graph 查询        (Phase 5)
  e.g. HAS_OPENING / FILLS / CONTAINS — 纯图查询
```

```
Load time (once, 2 batch LLM calls):
  IfcBuildingStorey.Name[]  →  LLM  →  storey_registry + _storey_by_num + _storey_by_cat
  IfcSpace.LongName[]       →  LLM  →  space_registry  + _space_by_type + _space_by_unit

Query time (per query, zero LLM):
  "level 6"        →  floor_num=6      →  _storey_by_num[6]           →  spatial_index key
  "ground floor"   →  category=ground  →  _storey_by_cat["ground"][0] →  spatial_index key
  "the kitchen"    →  type=kitchen     →  _space_by_type["kitchen"]   →  union of elements
  "unit 3B"        →  unit_id=3B       →  _space_by_unit["3b"]        →  union of elements
```

```python
def _build_storey_registry(self):
    """
    Parse every IfcBuildingStorey name into structured attributes via one LLM batch call.

    Stores:
        self.storey_registry   : {canonical_key → {"floor_num": int|None, "category": str, "raw": str}}
        self._storey_by_num    : {floor_num (int) → canonical_key}
        self._storey_by_cat    : {category (str) → [canonical_keys]}

    Called once at IFC load time.  Query time resolution uses _resolve_storey_query()
    with zero LLM calls (pure structured lookup + regex + difflib).
    """
    import json, re

    storeys = list(self.file.by_type("IfcBuildingStorey"))
    names = [s.Name or f"Storey_{s.id()}" for s in storeys]

    # ── Load prompt from YAML ─────────────────────────────────────────────
    import yaml
    from pathlib import Path
    _yaml = yaml.safe_load(
        (Path(__file__).parent.parent / "prompts" / "ifc_registry.yaml").read_text()
    )
    prompt = _yaml["storey_registry_prompt"].format(names=json.dumps(names))

    # ── LLM batch parse (single call, all storey names) ──────────────────
    parsed = []
    try:
        # adapt to your LLM client: self.llm.complete(prompt) / openai_client.chat(...)
        raw = self._llm_complete(prompt)
        parsed = json.loads(raw)
    except Exception:
        pass  # fall through to regex fallback below

    # ── Regex fallback (if LLM unavailable / parse error) ────────────────
    _CAT_RE = [
        (re.compile(r'ground|g/?f|lobby|entrance', re.I),    'ground'),
        (re.compile(r'basement|b\d|underground|carpark|park', re.I), 'basement'),
        (re.compile(r'roof|rooftop|sky\s*lobby', re.I),       'roof'),
        (re.compile(r'mezzanine|mezz', re.I),                 'mezzanine'),
        (re.compile(r'podium', re.I),                         'podium'),
    ]
    def _fallback_parse(name: str) -> dict:
        m = re.search(r'(-?\d+)', name)
        floor_num = int(m.group(1)) if m else None
        for pat, cat in _CAT_RE:
            if pat.search(name):
                return {"floor_num": floor_num, "category": cat}
        return {"floor_num": floor_num, "category": "normal"}

    if len(parsed) != len(names):          # LLM returned wrong length or failed
        parsed = [_fallback_parse(n) for n in names]

    # ── Build registry & secondary indices ───────────────────────────────
    self.storey_registry = {}
    self._storey_by_num  = {}
    self._storey_by_cat  = {}

    for name, info in zip(names, parsed):
        canonical = name.lower()
        floor_num = info.get("floor_num")
        category  = info.get("category", "normal")

        self.storey_registry[canonical] = {
            "raw":       name,
            "floor_num": floor_num,
            "category":  category,
        }
        if floor_num is not None:
            self._storey_by_num[floor_num] = canonical
        self._storey_by_cat.setdefault(category, []).append(canonical)
```

> **`_llm_complete(prompt)`**: 一个最简单的 helper，wrap 你现有的 LLM client（OpenAI/Anthropic SDK）；
> 只返回 `str`。若项目里已有 `self.llm` 或 `self.client`，直接替换该行即可。

```python
def _resolve_storey_query(self, query: str):
    """
    Resolve a natural-language storey reference → canonical key in storey_registry.

    Strategy (ordered by cost):
    1. Exact canonical match          O(1)   "6 - sixth floor" as-is
    2. Floor number extraction        O(1)   "level 6", "6f", "the 6th" → floor_num=6
    3. Category keyword detection     O(k)   "ground floor", "basement" → category lookup
    4. difflib fuzzy                  O(n)   typo fallback, last resort

    Returns canonical key (str) or None if unresolved.
    """
    import re
    from difflib import get_close_matches

    q = query.lower().strip()
    registry = getattr(self, 'storey_registry', {})
    if not registry:
        return None

    # 1. Exact canonical match
    if q in registry:
        return q

    # 2. Floor number extraction
    m = re.search(r'(-?\d+)', q)
    if m:
        num = int(m.group(1))
        if num in getattr(self, '_storey_by_num', {}):
            return self._storey_by_num[num]

    # 3. Category keyword detection
    #    These keywords are universal English vocabulary — not project-specific.
    #    Project-specific names were handled by LLM at load time (→ category label).
    _QUERY_CAT = {
        "ground": "ground", "g/f": "ground", "gf": "ground", "grade": "ground",
        "basement": "basement", "carpark": "basement", "underground": "basement",
        "roof": "roof", "rooftop": "roof",
        "mezzanine": "mezzanine", "mezz": "mezzanine",
        "podium": "podium",
    }
    by_cat = getattr(self, '_storey_by_cat', {})
    for kw, cat in _QUERY_CAT.items():
        if kw in q:
            candidates = by_cat.get(cat, [])
            if len(candidates) == 1:
                return candidates[0]
            if len(candidates) > 1:
                # Multiple floors in same category (e.g. B1/B2) — try floor_num again
                if m:
                    num = int(m.group(1))
                    for c in candidates:
                        if self.storey_registry[c].get("floor_num") == num:
                            return c
                return candidates[0]   # default to first (lowest elevation)
            break

    # 4. difflib fallback (typo correction only — conservative threshold)
    close = get_close_matches(q, list(registry.keys()), n=1, cutoff=0.60)
    return close[0] if close else None
```

```python
def _build_space_registry(self):
    """
    Parse every IfcSpace name into structured attributes via one LLM batch call.

    Uses LongName if available (more descriptive), falls back to Name.

    Stores:
        self.space_registry  : {canonical_key → {"space_type": str, "unit_id": str|None, "raw": str}}
        self._space_by_type  : {space_type (str) → [canonical_keys]}
        self._space_by_unit  : {unit_id (str)    → [canonical_keys]}

    space_type vocabulary (closed set for consistent querying):
        bedroom | master_bedroom | bathroom | kitchen | living_room | dining_room |
        corridor | lobby | office | storage | mechanical | parking |
        stairwell | elevator | balcony | toilet | unknown
    """
    import json, re

    spaces = list(self.file.by_type("IfcSpace"))
    if not spaces:
        self.space_registry = {}
        self._space_by_type = {}
        self._space_by_unit = {}
        return

    names = [s.LongName or s.Name or f"Space_{s.id()}" for s in spaces]

    # ── Load prompt from YAML ─────────────────────────────────────────────
    import yaml
    from pathlib import Path
    _yaml = yaml.safe_load(
        (Path(__file__).parent.parent / "prompts" / "ifc_registry.yaml").read_text()
    )
    space_types_str = " | ".join(_yaml["space_types"])
    prompt = _yaml["space_registry_prompt"].format(
        space_types=space_types_str,
        names=json.dumps(names),
    )

    # ── LLM batch parse (single call, all space names) ───────────────────
    parsed = []
    try:
        raw = self._llm_complete(prompt)
        parsed = json.loads(raw)
    except Exception:
        pass

    # ── Regex fallback ────────────────────────────────────────────────────
    _TYPE_RE = [
        (re.compile(r'master.?bed|主卧|master\s*room', re.I),    'master_bedroom'),
        (re.compile(r'bed|bedroom|卧室|睡房',            re.I),    'bedroom'),
        (re.compile(r'bath|wc|toilet|lavatory|卫生间|厕', re.I),  'bathroom'),
        (re.compile(r'kitchen|kitch|厨房',               re.I),    'kitchen'),
        (re.compile(r'living|lounge|客厅',               re.I),    'living_room'),
        (re.compile(r'dining|餐厅',                      re.I),    'dining_room'),
        (re.compile(r'corridor|hallway|走廊|过道',        re.I),    'corridor'),
        (re.compile(r'lobby|reception|大堂',             re.I),    'lobby'),
        (re.compile(r'office|study|书房|办公',            re.I),    'office'),
        (re.compile(r'store|storage|storeroom|储藏',     re.I),    'storage'),
        (re.compile(r'mech|plant|machine|机房',          re.I),    'mechanical'),
        (re.compile(r'park|carpark|garage|车库',         re.I),    'parking'),
        (re.compile(r'stair|楼梯',                       re.I),    'stairwell'),
        (re.compile(r'lift|elevator|elev|电梯',          re.I),    'elevator'),
        (re.compile(r'balcony|terrace|阳台',             re.I),    'balcony'),
    ]
    _UNIT_RE = re.compile(r'\b([A-Z]?\d{1,4}[A-Z]?)\b')  # e.g. 3B, A02, 601

    def _fallback_parse_space(name: str) -> dict:
        for pat, stype in _TYPE_RE:
            if pat.search(name):
                um = _UNIT_RE.search(name)
                return {"space_type": stype, "unit_id": um.group(1) if um else None}
        um = _UNIT_RE.search(name)
        return {"space_type": "unknown", "unit_id": um.group(1) if um else None}

    if len(parsed) != len(names):
        parsed = [_fallback_parse_space(n) for n in names]

    # ── Build registry & secondary indices ───────────────────────────────
    self.space_registry = {}
    self._space_by_type = {}
    self._space_by_unit = {}

    for name, info in zip(names, parsed):
        canonical  = name.lower()
        space_type = info.get("space_type", "unknown")
        unit_id    = (info.get("unit_id") or "").lower() or None

        self.space_registry[canonical] = {
            "raw":        name,
            "space_type": space_type,
            "unit_id":    unit_id,
        }
        self._space_by_type.setdefault(space_type, []).append(canonical)
        if unit_id:
            self._space_by_unit.setdefault(unit_id, []).append(canonical)
```

### 修改 B4 — 新增方法 `_resolve_space_query()`

位置: 紧接在 `_build_space_registry()` 之后插入。

**注意**: 与 storey 不同，space 查询可能匹配多个房间（一栋楼有多个厨房），
故返回 `List[str]`（canonical key 列表），由 `find_elements_in_space()` 聚合元素。

```python
def _resolve_space_query(self, query: str) -> list:
    """
    Resolve a room/space reference → list of matching canonical keys in space_registry.

    Returns a list because multiple spaces can share the same type
    (e.g. "the kitchen" may match kitchens on multiple floors).

    Strategy:
    1. Exact canonical match          → [exact_key]
    2. Space type keyword detection   → _space_by_type[type]
    3. Unit ID detection              → _space_by_unit[unit_id]
    4. difflib fuzzy on registry keys → [best_match]
    """
    from difflib import get_close_matches

    q = query.lower().strip()
    registry = getattr(self, 'space_registry', {})
    if not registry:
        return []

    # 1. Exact canonical match
    if q in registry:
        return [q]

    # 2. Space type keyword detection
    #    Keywords are stable English/Chinese vocabulary for room types.
    _QUERY_TYPE = {
        "master bedroom": "master_bedroom", "master bed": "master_bedroom",
        "bedroom": "bedroom", "bed room": "bedroom",
        "bathroom": "bathroom", "bath": "bathroom", "toilet": "toilet", "wc": "toilet",
        "kitchen": "kitchen",
        "living room": "living_room", "living": "living_room", "lounge": "living_room",
        "dining room": "dining_room", "dining": "dining_room",
        "corridor": "corridor", "hallway": "corridor",
        "lobby": "lobby",
        "office": "office",
        "storage": "storage", "store room": "storage", "storeroom": "storage",
        "mechanical": "mechanical", "plant room": "mechanical",
        "parking": "parking", "carpark": "parking",
        "stairwell": "stairwell", "staircase": "stairwell",
        "elevator": "elevator", "lift": "elevator",
        "balcony": "balcony", "terrace": "balcony",
    }
    by_type = getattr(self, '_space_by_type', {})
    # Match longest keyword first to avoid "bed" matching before "master bedroom"
    for kw in sorted(_QUERY_TYPE, key=len, reverse=True):
        if kw in q:
            candidates = by_type.get(_QUERY_TYPE[kw], [])
            if candidates:
                return candidates

    # 3. Unit ID detection (e.g. "unit 3B", "apartment A02")
    import re
    um = re.search(r'\b([a-z]?\d{1,4}[a-z]?)\b', q)
    if um:
        uid = um.group(1)
        by_unit = getattr(self, '_space_by_unit', {})
        if uid in by_unit:
            return by_unit[uid]

    # 4. difflib fallback
    close = get_close_matches(q, list(registry.keys()), n=3, cutoff=0.60)
    return close
```

```python
def find_elements_in_space(self, room_query: str):
    """Spatial lookup: storey name or room/space name.

    Resolution order:
    1. Exact substring on spatial_index         fast path, original behaviour
    2. Structured storey resolution             "level 6" → floor num lookup
    3. Structured space resolution              "the kitchen" → space type lookup
    4. difflib on spatial_index keys            typo/fuzzy fallback
    """
    q = room_query.lower().strip()
    if not q:
        return []

    # 1. Exact substring (original behaviour)
    matches = [elems for key, elems in self.spatial_index.items() if q in key]
    if matches:
        return [e for elems in matches for e in elems]

    # 2. Structured storey resolution
    #    Handles: "level 6", "ground floor", "B1", "sixth floor", ...
    storey_key = self._resolve_storey_query(q)
    if storey_key and storey_key in self.spatial_index:
        return self.spatial_index[storey_key]

    # 3. Structured space resolution
    #    Handles: "the kitchen", "master bedroom", "unit 3B", ...
    #    Returns multiple matching canonical keys (e.g. kitchens on all floors)
    space_keys = self._resolve_space_query(q)
    if space_keys:
        results = [e for k in space_keys if k in self.spatial_index
                     for e in self.spatial_index[k]]
        if results:
            return results

    # 4. difflib fallback on all spatial_index keys
    from difflib import get_close_matches
    close = get_close_matches(q, list(self.spatial_index.keys()), n=1, cutoff=0.60)
    if close:
        return self.spatial_index[close[0]]

    return []
```

```python
def query_elements_in_space(self, space_name: str, ifc_type: str = "") -> List[Dict]:
    """Query elements within a named room/space (memory + Neo4j)."""
    if not self.neo4j_conn:
        # Memory mode: use fuzzy-aware find_elements_in_space
        results = self.find_elements_in_space(space_name)
        if ifc_type:
            results = [r for r in results if r.get("type") == ifc_type]
        return results

    type_clause = "AND e.ifc_type = $ifc_type" if ifc_type else ""
    query = f"""
    MATCH (sp:IFCSpace)-[:CONTAINS]->(e:IFCElement)
    WHERE toLower(sp.name) CONTAINS toLower($space_name)
    {type_clause}
    RETURN e.guid as guid, e.name as name, e.ifc_type as type,
           sp.name as space
    """
    result = self.neo4j_conn.run(query, space_name=space_name.lower(),
                                  ifc_type=ifc_type)
    return [dict(r) for r in result]


def query_elements_by_name_keyword(self, keyword: str) -> List[Dict]:
    """Search elements by name keyword (fuzzy, memory + Neo4j)."""
    if not self.neo4j_conn:
        # ✅ CORRECTED: search element .name values, NOT spatial_index keys
        kw = keyword.lower()
        results, seen = [], set()
        for elems in self.spatial_index.values():
            for e in elems:
                if e["guid"] not in seen and kw in (e.get("name") or "").lower():
                    results.append(e)
                    seen.add(e["guid"])
        return results

    query = """
    MATCH (e:IFCElement)
    WHERE toLower(e.name) CONTAINS toLower($keyword)
    RETURN e.guid as guid, e.name as name, e.ifc_type as type
    LIMIT 20
    """
    result = self.neo4j_conn.run(query, keyword=keyword)
    return [dict(r) for r in result]


def query_elements_by_neighbor(self, ifc_type: str, neighbor_type: str) -> List[Dict]:
    """Find elements of ifc_type structurally connected to neighbor_type (Neo4j only).

    Uses HAS_OPENING and FILLS relationships — these are the only structural
    adjacency edges currently in the graph. NEAR edges are not yet built
    (deferred to Step 3 Topological microservice).
    """
    if not self.neo4j_conn:
        return []  # No memory fallback — topology requires graph

    # ✅ CORRECTED: removed CONTAINS (Storey→Element, wrong direction for neighbor)
    # Only HAS_OPENING and FILLS are valid element↔element adjacency here
    query = """
    MATCH (e:IFCElement)-[:HAS_OPENING|FILLS]-(nb:IFCElement)
    WHERE e.ifc_type = $type
      AND nb.ifc_type = $neighbor_type
    RETURN DISTINCT e.guid as guid, e.name as name, e.ifc_type as type
    """
    result = self.neo4j_conn.run(query, type=ifc_type,
                                  neighbor_type=neighbor_type)
    return [dict(r) for r in result]
```

> **注**: `neighbor+type` 目前只能通过 Neo4j 的 `HAS_OPENING`/`FILLS` 关系工作，
> 仅覆盖"门/窗在洞口里"这类结构关系。完整空间邻接（柱旁边的墙等）需要 Step 3 建
> `NEAR` 关系后才生效。Memory mode 返回空并 graceful degrade 到下一条规则。

**位置**: 在 `_execute_memory()` return 之前，对候选集做属性过滤。

```python
def _apply_property_filter(self, candidates: List[Dict], params: dict) -> List[Dict]:
    """
    Post-filter candidates by Pset properties.
    Called after spatial/type retrieval, before returning results.
    Only runs if any property constraint is present in params.
    """
    _PROP_KEYS = ("firerating", "loadbearing", "isexternal",
                  "material", "acousticrating")
    active = {k: params[k] for k in _PROP_KEYS if k in params and params[k] is not None}
    if not active:
        return candidates  # no property constraint — skip entirely

    filtered = []
    for c in candidates:
        props = self.engine.get_element_properties(c["guid"])
        flat = {}
        for pset in props.get("PropertySets", {}).values():
            for k, v in pset.items():
                flat[k.lower()] = v
        if all(flat.get(k) == v for k, v in active.items()):
            filtered.append(c)
    # Graceful degrade: if filter removes everything, return unfiltered
    return filtered if filtered else candidates
```

> 并在 `_build_params()` 里映射到 params 时自动生效。当前 Phase 5 不会触发此函数。

> **时间节点**: Mid-review 之后
> **定位**: 独立 microservice，作为新的论文 contribution
> **价值**: 当前最大剩余瓶颈——在 storey+type 过滤后还有 50 个同类候选时，
> 拓扑关系是唯一能精确定位的维度（"the window next to the elevator shaft"）

## 核心思路

```
现状 (Step 1 后):  storey + type → ~15 个候选
                   ↑ 已是语义上限，text/image 无法再区分

拓扑增强后:  storey + type + 空间邻接 → ~2-3 个候选
             ↑ 利用"这个元素在哪个房间旁边"这一几何事实
```

**关键洞察**: IFC 文件本身已经编码了完整的空间拓扑信息：
- `IfcRelSpaceBoundary` — 哪些构件构成了空间的边界（墙、门、窗属于哪个房间）
- `IfcRelConnectsSpaceElements` — 空间之间的连接关系
- 这些关系**不需要几何计算**，直接解析 IFC 即可

## Component 1 — IFC Space Boundary Parser

**文件**: `src/ifc_engine.py` — 新增方法，在 `_create_element_relationships()` 之后

```python
def _create_space_boundary_relationships(self) -> int:
    """
    Parse IfcRelSpaceBoundary to build Space-Element boundary graph.

    IfcRelSpaceBoundary links spaces to their bounding elements (walls, doors, windows).
    This gives us which elements "belong to" a space at the boundary level,
    which is more precise than simple spatial containment.

    Creates Neo4j relationships:
        (IFCSpace)-[:BOUNDS]->(IFCElement)   ← element forms space boundary
    """
    count = 0
    for rel in self.file.by_type("IfcRelSpaceBoundary"):
        space = rel.RelatingSpace
        element = rel.RelatedBuildingElement
        if space is None or element is None:
            continue
        if element.is_a("IfcOpeningElement"):
            continue
        self._create_relationship(
            "IFCSpace", space.GlobalId,
            "BOUNDS",
            "IFCElement", element.GlobalId
        )
        count += 1
    return count
```

**调用位置**: `export_to_neo4j()` 里加一行：
```python
stats["relationships"] += self._create_space_boundary_relationships()
```

## Component 2 — Space Adjacency Builder

**原理**: 如果两个 Space 共享同一个 boundary element（如一堵墙隔开两个房间），
则这两个空间相邻。

```python
def _create_space_adjacency_relationships(self) -> int:
    """
    Derive ADJACENT_TO edges between spaces from shared boundary elements.

    Algorithm:
      1. Build element_guid → [space_guids] mapping from IfcRelSpaceBoundary
      2. For each element bounded by 2+ spaces, mark those spaces as adjacent
      3. Write (spaceA)-[:ADJACENT_TO {via: element_type}]->(spaceB) to Neo4j

    No geometry computation required — purely relational parsing.
    """
    from collections import defaultdict

    # element → [spaces that bound it]
    element_to_spaces = defaultdict(list)
    for rel in self.file.by_type("IfcRelSpaceBoundary"):
        space = rel.RelatingSpace
        element = rel.RelatedBuildingElement
        if space and element and not element.is_a("IfcOpeningElement"):
            element_to_spaces[element.GlobalId].append(space.GlobalId)

    count = 0
    created = set()
    for elem_guid, space_guids in element_to_spaces.items():
        if len(space_guids) < 2:
            continue  # boundary element shared by only one space — skip
        # All pairs of spaces sharing this boundary
        for i in range(len(space_guids)):
            for j in range(i + 1, len(space_guids)):
                pair = tuple(sorted([space_guids[i], space_guids[j]]))
                if pair not in created:
                    self._create_relationship(
                        "IFCSpace", pair[0],
                        "ADJACENT_TO",
                        "IFCSpace", pair[1]
                    )
                    created.add(pair)
                    count += 1
    return count
```

## Component 3 — 新 QueryPlanner 规则（接入拓扑）

Step 3 完成后，在 `constraints_to_query.py` 加入两条拓扑规则：

**新增字段** (追加到 `Constraints`)：
```python
adjacent_space: Optional[str] = None
# e.g. "elevator shaft", "corridor", "stairwell"
# Extracted from: "the window facing the corridor"
# Enables: find elements in space ADJACENT_TO the named reference space
```

**新 QueryPlanner 规则** (priority -1, 最高优先):
```python
{
    "priority": -1,
    "strategy": "adjacent_space+type",
    "requires": ["adjacent_space", "ifc_class"],
    "description": "Topological: element in space adjacent to reference space",
    "template_cypher": """
        MATCH (ref:IFCSpace)-[:ADJACENT_TO]-(adj:IFCSpace)-[:BOUNDS]->(e:IFCElement)
        WHERE toLower(ref.name) CONTAINS toLower($adjacent_space)
          AND e.ifc_type = $type
        RETURN DISTINCT e.guid as guid, e.name as name, e.ifc_type as type,
               adj.name as space
    """
},
{
    "priority": -0.5,
    "strategy": "space_boundary+type",
    "requires": ["space_name", "ifc_class"],   # upgrades existing space+type
    "description": "Boundary-precise: element on the boundary of a named space",
    "template_cypher": """
        MATCH (sp:IFCSpace)-[:BOUNDS]->(e:IFCElement)
        WHERE toLower(sp.name) CONTAINS toLower($space_name)
          AND e.ifc_type = $type
        RETURN e.guid as guid, e.name as name, e.ifc_type as type,
               sp.name as space
    """
},
```

## Component 4（可选）— Floorplan Visual Grounding

将平面图视觉信息与 IFC IfcSpace 对齐，提升 LLM 提取 `space_name` 的准确率。

**流程**:
```
floorplan image
    ↓ VLM (Gemini / GPT-4V)
room label extraction: ["Living Room", "Kitchen", "Master Bedroom", ...]
    ↓ fuzzy match
IfcSpace.LongName candidates from IFC
    ↓ highest similarity
aligned space_name → injected into prompt context
```

**新文件**: `src/v2/floorplan_space_aligner.py`
```python
class FloorplanSpaceAligner:
    """
    Align VLM-extracted room labels from floorplan with IfcSpace.LongName.

    Used to enhance space_name accuracy in Constraints extraction.
    """
    def __init__(self, ifc_engine: IFCEngine):
        self.known_spaces = [
            space.LongName or space.Name
            for space in ifc_engine.file.by_type("IfcSpace")
            if space.LongName or space.Name
        ]

    def align(self, raw_label: str) -> Optional[str]:
        """Fuzzy-match raw VLM label to canonical IFC space name."""
        from difflib import get_close_matches
        matches = get_close_matches(raw_label, self.known_spaces,
                                    n=1, cutoff=0.6)
        return matches[0] if matches else None
```
