# Legacy Analysis Plot Scripts

This folder keeps older one-off plotting and diagnostic scripts that are not part of the canonical Phase 4 plot suite.

Use the top-level suite for current thesis figures:

```bash
python mscd_demo/evaluation/analysis/generate_phase4_plot_suite.py --suite thesis
```

Scripts here are retained for provenance and historical regeneration. If one becomes current again, move it back to `evaluation/analysis/`, wire it into `generate_phase4_plot_suite.py`, and document it in `evaluation/analysis/README.md`.
